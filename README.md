# 『OpenUSD実践入門』のサンプルコード

書籍『OpenUSD実践入門 ― NVIDIA認定資格への最短ルート』の序章から第22章までの実習ファイルを収録しています。

## 使い方

本で読む章を決めたら、下の対応表からその章の README を開いてください。「事前準備」には必要な入力ファイルと、そのファイルを作る章へのリンクがあります。球のステージは第1章、親子階層は第2章、家から通りを組み立てる実習は第4章から、それぞれ空の作業フォルダで始められます。

番号フォルダにはスクリプトを置き、生成物は `work` 以下で引き継ぎます。各章のコマンドは、リポジトリのルートまたは章フォルダから新しい PowerShell で始められます。最初からやり直すときは、空の作業場所に新しくクローンすると、以前の生成物を残せます。

## 共通環境

第1章以降の Python サンプルは、Windows の PowerShell で実行します。Python のパッケージと仮想環境の管理には uv を使います。インストールするには次のコマンドを実行してください。[uv 公式のインストール手順](https://docs.astral.sh/uv/getting-started/installation/)

```powershell
winget install --id=astral-sh.uv -e
```

新しい PowerShell を開き、次の順に環境を用意します。取得済みなら、リポジトリのルートで `uv sync --locked` を実行してください。

```powershell
uv --version
git clone https://github.com/regonn/open_usd_regonn.git
Set-Location open_usd_regonn
uv sync --locked
```

`.python-version` は Python 3.13 系を指定し、`uv.lock` は `usd-core` を 26.11 に固定しています。序章は Kit 110.4.1 の Script Editor を使います。本文の CLI 実習には conda-forge の `openusd` 26.08 を使います。追加の環境が必要な章には、その準備を記載しています。
